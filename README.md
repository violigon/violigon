## 🧭 About me

- 🔧 I build things where **code meets electronics**: embedded firmware, IoT devices, robotics and the web apps that talk to them.
- 🏢 Running **Oligon Hardware**, where I design and ship custom hardware solutions.
- 🖥️ Day to day I also work with **IT infrastructure and automation**: networks, asset management, workflow automation and integrations between internal tools.
- 🎓 I have taught programming bootcamps (backend with Node.js, Python, HTML/CSS) and enjoy turning complex topics into simple examples.
- 🌱 Currently exploring **AI tooling and agents** applied to everyday workflows.
